# Security Policy

## Supported Versions

This project is early-stage. Security fixes will generally target the latest mainline code.

## Reporting A Vulnerability

Please do not open public issues for suspected security vulnerabilities.

Instead, report them privately to the maintainers with:

- a description of the issue
- affected versions or commits
- reproduction details if available
- potential impact

We will acknowledge receipt, investigate, and coordinate disclosure when a fix is ready.

## Scope Notes

Current risk areas are likely to center on dependency management, file parsing, and resource usage when loading untrusted images.
